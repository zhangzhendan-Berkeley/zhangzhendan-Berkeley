Project 3A: Image Warping & Mosaicing — Project Report

Author: Zhang Zhendan

Overview

This project implements image warping and mosaicing using manually provided point correspondences and a RANSAC-based homography estimation. The pipeline is: point correspondence → homography (DLT + RANSAC) → inverse warp → interpolation (nearest / bilinear) → alpha blending / Laplacian pyramid blending.

Data: Three photographic pairs

I captured three pairs of photographs. Each pair consists of a left and a right image. Each capture was performed by rotating the camera around its optical center (no intended translation) so that the geometric relation between the two images is well-modeled by a homography (projective transform).

Step 1 — Correspondences & RANSAC

For each pair I provided 32 manually-annotated point correspondences (left ↔ right). To make the homography robust to annotation errors, I used a simple RANSAC loop: repeatedly sample 4 points, compute a candidate homography by DLT, count inliers (reprojection error < threshold), and finally re-fit H using all inliers.

Direct Linear Transform (DLT) formulation

Given homogeneous points $(x,y,1)^\top$ and $(x',y',1)^\top$, the homography $H$ satisfies $$\lambda \begin{bmatrix} x' \\ y' \\ 1 \end{bmatrix} = H \begin{bmatrix} x \\ y \\ 1 \end{bmatrix}.$$ Using DLT we construct linear equations $A h = 0$ and solve for $h$ (the 9 entries of $H$) with SVD, then normalize $H$ so $H_{33}=1$.

Step 2 — Warping (inverse mapping) and interpolation

I implemented two inverse-warping functions (no high-level warpers used): warpImageNearestNeighbor(im, H) and warpImageBilinear(im, H). For each pixel in the target canvas I compute $(x,y) = H^{-1}(x',y',1)$ and sample the source image using:

  • Nearest neighbor: round coordinates to the nearest integer pixel.
  • Bilinear interpolation: compute weighted average of the four neighboring pixels using fractional offsets.

Equations (bilinear)

If the mapped source point is $(u,v)$ and its integer floor is $(i,j)$ with fractional parts $a=u-i$, $b=v-j$, then $$I(u,v) \approx (1-a)(1-b)I(i,j) + a(1-b)I(i+1,j) + (1-a)b I(i,j+1) + ab I(i+1,j+1).$$

Step 3 — Blending into mosaics

After warping, I blend the warped left image with the reference right image using pixel-wise weighted averaging (alpha blending). The alpha mask was chosen to emphasize the center of each image and fall off toward the borders.

Alpha mask construction

I used a radial/edge-distance style falloff so alpha is near 1 in interior pixels and decays toward 0 near edges. For pixel $(x,y)$ on an image of width $W$ and height $H$, a simple mask is:

$$\alpha(x,y) = \max\big(0,\; \min(d_{\text{left}}, d_{\text{right}}, d_{\text{top}}, d_{\text{bottom}})/r\big)$$
where $d_{\text{left}} = x$, $d_{\text{right}} = W-1-x$, $d_{\text{top}} = y$, $d_{\text{bottom}} = H-1-y$ and $r$ is a falloff radius.

Laplacian pyramid (optional refinement)

A two-level Laplacian pyramid was also implemented to reduce ghosting on high-frequency content. The pipeline: build Gaussian pyramids for both images and the mask, compute Laplacian levels, blend each level with the mask, and reconstruct.

Discussion & Observations

  • Interpolation trade-offs: Nearest-neighbor is much faster but introduces blockiness; bilinear is slower but yields visually smoother warps.
  • RANSAC is essential: Manually annotated point sets often include imperfect clicks; RANSAC reliably rejects outliers and produces stable homographies.
  • Blending limits: Weighted averaging performs well for modest misalignment, but residual parallax or slight translations during capture can still cause faint ghosting — Laplacian pyramid blending reduces these artifacts for high-frequency content.
  • Practical tip: If you anticipate rotations only, enforcing the camera center constraint and using larger, accurately placed correspondences on distant features improves results.

CS180 Project 3B: Feature Matching for Auto-Stitching

Author: Zhang Zhendan

Overview

In this project, I implemented an automatic image stitching pipeline following the paper "Multi-Image Matching using Multi-Scale Oriented Patches" by Brown et al., with several simplifications. The main steps include detecting Harris corners, applying ANMS, extracting feature descriptors, matching features, and computing homographies using RANSAC to stitch images into mosaics.
